# tg-client

`tg-client` — это легковесный клиент для Telegram, использующий библиотеку `tdlib`. Он отвечает за работу с сессией отдельного пользователя и пересылку входящих голосовых/видео сообщений в сервис транскрибации `funasr`.

## Архитектура
Работает в рамках архитектуры **"per-user pod"**: для каждого подключенного Telegram-аккаунта в Kubernetes поднимается свой собственный изолированный pod. Управление подами осуществляет `tg-client-manager`.

## Основные функции
1. **Перехват голосовых сообщений и кружочков** (видеосообщений).
2. **Отправка на транскрибацию**: Аудио переводится в `base64` и отправляется на `/v1/transcribe-base64` в `funasr`. Реализован механизм long-polling для получения готового текста без таймаутов.
3. **Отправка расшифровки**: Возвращает в чат текст (с автоматическим разбиением на сообщения по лимиту символов Telegram).
4. **Клонирование голоса (SAMESAME)**: Поддерживает явную команду `!SAMESAME! [язык] текст` в ответ на аудио/кружок.
   - Извлекает аудио оригинала.
   - Синтезирует текст в голос отправителя (с помощью сервиса SAMESAME).
   - Таймаут на ответ составляет **15 минут**, чтобы стабильно работать с CPU-инференсом `SAMESAME`.
   - *Примечание: Автоматический синтез голоса на все входящие сообщения полностью удален для экономии серверных ресурсов.*

## Переменные окружения
- `TARGET_USER_ID`: Telegram ID владельца сессии.
- `REDIS_URL`: Подключение к Redis (для хранения сессий и статистики).
- `FUNASR_URL`: URL `funasr`.
- `ASR_SECRET`: Токен для ASR.
- `SAMESAME_URL`: URL `samesame` сервиса.
- `SAMESAME_SECRET`: Секрет для голосового клонирования.

## Развертывание
Не требует ручной сборки. Собирается и деплоится в составе общего развертывания или целевого `deploy-targeted.sh tg-client`.
Образ используется как шаблон для создания подов компонентом `tg-client-manager`.
